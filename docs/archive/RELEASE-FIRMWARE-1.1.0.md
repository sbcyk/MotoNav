# 固件 1.1.0：主页改为赐福场景

只适用于微雪 ESP32-S3-Touch-AMOLED-1.75（466×466）。本轮只改圆屏主页，不涉及 BLE 协议与手机端。

## 背景

原有主页是 40×26 的像素骑手精灵，常驻时钟、`ready` / `no link` 文字、蓝牙名、固件版本和页码点，屏幕信息密度偏高。本轮把主页改成极简的赐福（Site of Grace）场景：一根从地面升起的金色光丝、脚下法阵环和上升光尘，其余信息收进点击浮层。

## 改动

### 主页画面

- 赐福、法阵、土堆、碎石、光尘全部为代码绘制，不依赖图片素材。
- 不再绘制人物。画面按褪色者第一人称视角理解。
- 去掉常驻时钟、连接状态文字、蓝牙名、固件版本和页码点。
- 点击主页打开信息浮层：时间、日期、连接状态、蓝牙名、电量、固件版本与 QSPI 频率；再次点击或 6 秒后自动关闭。浮层只盖在场景上方，不是独立页面。
- 滑动换页与侧键翻页行为不变，页码点仍在音乐页和天气页显示。

### 连接状态

| 状态 | 画面 |
|---|---|
| 未连接 | 赐福呼吸闪烁，光尘上升 |
| 连接成功 | 光丝骤亮，法阵扩散，光点汇聚，灵马显现 |
| 导航中断 | 灵马反向消散，回到赐福场景 |

### 渲染方式

主页改为整帧重画并设置 `frameIsMap`，走 `flushAsync()` 异步推屏。此前主页只在精灵帧变化时重画，现在 `HOME_FRAME_MS=40`（25fps），推屏任务较慢时由 `flushWait()` 自然节流，不额外阻塞主循环。

灵马立绘从 2bpp 升级为 4bpp 索引色，按到赐福的距离分阶明暗，交界处使用棋盘抖动。生成脚本为 `scripts/home_sprites.py`。

## 构建与验证

`firmware/build.py` 在 Windows 下读取带中文注释的 `FirmwareConfig.h` 时按默认 GBK 解码，会直接抛出 `UnicodeDecodeError`，本轮补上 `encoding='utf-8'`，manifest 写出也统一为 UTF-8。

编译结果：app 约 1.30MB / 3MB 分区（41%），动态内存 28%，无编译警告（除 SensorLib 自带的弃用提示）。

版本号五处同步位置见 `AGENTS.md`。本轮起固件版本不再带 `-sidebtn` 后缀。

镜像归档在仓库外的 `..\builds\2026-11-03-home-grace\`，包含 SHA256。已烧录到 COM4 并通过写入校验，启动日志版本一致，IPC 栈水位正常。
