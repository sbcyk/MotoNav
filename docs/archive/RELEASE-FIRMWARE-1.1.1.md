# 固件 1.1.1：修正赐福场景绘制与状态问题

只适用于微雪 ESP32-S3-Touch-AMOLED-1.75。本轮只改 `src/pages/HomePage.h`、`src/pages/PageNavigation.h` 和灵马立绘位置。

## 修正的问题

### 法阵最亮的环被自己填掉

`hGraceRing()` 原先按"描三圈环，再 `fillEllipse` 填内圈"的顺序绘制，最后一次填充的边界正好覆盖中间那圈描边，等于白画；土堆又盖住了环的下半段。现在改为先填底、再描环，土堆提前到法阵之前绘制。

### 光尘没有真正上升

`hDust()` 的相位 `ph` 只由粒子序号算出，与时间无关，34 个光尘实际固定在原地左右摆动。相位加入 `now` 项，并改用 `i / N` 均匀分布，避免原系数让粒子聚成几簇。

### 切页后召唤过渡状态残留

`hTransDir` 只在主页动画循环里清零。切换页面后动画循环不再执行，回到主页时若不再调用 `drawWaiting()`，会带着旧的扩散环和亮度继续显示。`slideCommit()` 回到主页的分支现在统一调用 `drawWaiting(waitSt)`，过渡状态随之归零。

### 浮层在异步推屏途中改写画布

`homeToggleInfo()` 原来直接往当前画布绘制，而上一帧可能正由核心 0 的推屏任务读取，存在画面撕裂风险。现在浮层并入 `hDrawScene()` 整帧绘制，开关和时间更新只置脏标记，由 `animateCat()` 统一重画。

## 画面调整

- 光丝基准高度 132 → 168，另加 ±12 的高度呼吸；构图上移。
- 亮芯按 `u^0.7` 衰减，根部约 12px 宽，顶端保留 2px，避免细到断成虚线。
- 法阵增加每 2.4 秒一圈的扩散波。
- 灵马右移 20px，不再压在法阵右沿上；去掉独立的上下浮动。
- 召唤改为自下而上逐行显形，再整体提亮；时长 1200ms → 1000ms。
