# 需求清单

**需求、进度、阻塞项、验收记录只在本文件维护。** 其他文档只写规范、架构和历史，不复述需求状态。改需求只改这里。

不记录"当前版本 / 当前 HEAD / 当前分支"这类随时会变的快照，需要时用 `git log -1`、`git status -sb`、`git tag -l` 现查。

**某次版本改了什么、怎么验证 → `docs/archive/RELEASE-FIRMWARE-<版本>.md`**，此处只留一句指向。

## 状态口径

| 状态 | 含义 |
|---|---|
| 待办 | 已确定要做，未开工 |
| 阻塞 | 已确定要做，缺前置（素材 / 决策 / 设备） |
| 进行中 | 已开工 |
| 已完成 | 已实现，并在设备或 CI 上验证过 |
| 已取消 | 明确不做 |
