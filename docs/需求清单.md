- **内容**：像素风黄昏赐福，两态分别是褪色者独坐赐福旁 / 托雷特现身、他起身牵缰。两态**共用一张背景**：母版 `home-v3-standing.png`（站姿牵马）把黄金树、王城、峡谷一起带进画面，断开态 `home-v3-seated.png` 是同源生成的坐姿版；**只把"人马矩形"和"赐福柱带"换成后者的像素，其余逐像素复制母版**。切换时人按纵向扫描从脚往上起身、马由蓝白粒子聚拢显形，断开反向走 = 马先散、人后坐。赐福随姿态变：坐火（未连接，人在赐福里交互）亮而盛——亮档 16、火苗 23×12、光尘 20 颗升 96 px、闪烁粒子 10 颗；起身出发（已连接，不再交互）后整圈按椭圆压暗一档（`hDimBless`，中心压 44%），亮档降到 9、光尘 10 颗、粒子 5 颗。**强弱只能靠压暗做**：母版的火已接近饱和，加色加多加少都是白。v2.4 起加常驻信息层（`HomeBand.h`）：贴圆边的金色细环 + 12/3/6/9 四向星芒，时间 8x 居中、日期带星期、地点靠左下带菱点、天气靠右下；文字压在椭圆柔和压暗上（`hSoftDim`，中心暗、边缘 (1-d²)² 淡出），不用描边也不压矩形色块。点击屏幕仍可开信息浮层（连接状态 / 蓝牙名 / 电量 / 版本），6 秒自动收起。素材 233×233 8bpp、两态共用一张调色板，显示 2× 最近邻放大。
- **约束**：保留 `WAIT_READY / WAIT_NOLINK / WAIT_LOST` 三态语义；对外接口 `drawWaiting` / `animateCat` / `drawHomeClock` 不变（`Buttons.h`、`PageNavigation.h` 依赖）；**人马矩形与赐福柱带之外两态必须逐像素相同**（v2.4 起柱带也允许不同：两态的柱一有一无）——`scripts/home_sprites.py` 每次生成都校验，不为 0 直接报错。这是“背景不跳”的唯一依据，改素材、改取景或改矩形之后都要重新验这一次；光效与局部擦除裁到圆内（`hCircleSpan`）；**“连上没有”只认 `homeLinkReady()`**（`src/connectivity/Bluetooth.h`，v2.1.1 起只看 `bleConnected`），主循环、`renderPage`、侧键回首页、状态栏小绿点、`#C` 一律走它；认证（`bleAuthed`）只用于数据通道，不要混进画面判定
- **变更记录**：见 `CHANGELOG.md` 的 `[2.1.0]`、`[2.1.1]`、`[2.2.0]` 段
