- **约束**：保留 `WAIT_READY / WAIT_NOLINK / WAIT_LOST` 三态语义；对外接口 `drawWaiting` / `animateCat` / `drawHomeClock` 不变（`Buttons.h`、`PageNavigation.h` 依赖）；**人马矩形之外两态必须逐像素相同**——`scripts/home_sprites.py` 每次生成都校验，不为 0 直接报错。这是“背景不跳”的唯一依据，改素材、改取景或改矩形之后都要重新验这一次；光效与局部擦除裁到圆内（`hCircleSpan`）；**“连上没有”只认 `homeLinkReady()`**（`src/connectivity/Bluetooth.h`，v2.1.1 起只看 `bleConnected`），主循环、`renderPage`、侧键回首页、状态栏小绿点、`#C` 一律走它；认证（`bleAuthed`）只用于数据通道，不要混进画面判定
- **变更记录**：见 `CHANGELOG.md` 的 `[2.1.0]`、`[2.1.1]`、`[2.2.0]` 段
